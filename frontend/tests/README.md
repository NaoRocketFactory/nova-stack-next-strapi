## 🧪 Testing Setup

Testing is not included by default to keep this starter kit lightweight.

You can easily integrate one of the following setups:

- **Vitest + React Testing Library** (recommended for unit and component tests)
- **Playwright** (for end-to-end testing)
- **Jest** (if you prefer the classic setup)

Example setup guide:  
https://nextjs.org/docs/app/building-your-application/testing/jest
